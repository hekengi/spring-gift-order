# spring-gift-order

## Step3 - 배포하기 

### 기능 요구 사항
지금까지 만든 선물하기 서비스를 배포하고 클라이언트와 연동할 수 있어야 한다.

- 지속적인 배포를 위한 배포 스크립트를 작성한다.
- 클라이언트와 API 연동 시 발생하는 보안 문제에 대응한다.
  - 서버와 클라이언트의 Origin이 달라 요청을 처리할 수 없는 경우를 해결한다.

### 구현해야 할 작업 순서

#### 1. AWS EC2 인스턴스 생성

#### 2. 배포 스크립트 작성
- `deploy.sh` 파일 생성
- 기존 애플리케이션 종료 로직 작성
- 새 애플리케이션 배포 로직 작성
- 실행 권한 부여

#### 3. CORS 설정 추가
- `WebConfig.java`에 CORS 설정 메서드 추가
- 클라이언트 Origin 허용 설정
- HTTP 메서드 및 헤더 허용 설정

#### 4. 애플리케이션 빌드
- Gradle을 사용하여 JAR 파일 빌드
- 테스트 제외하고 빌드 실행

#### 5. 서버 환경 설정
- EC2 인스턴스에 Java 설치
- 애플리케이션 JAR 파일 업로드
- 환경 변수 설정 (카카오 API 키)

#### 6. 배포 실행
- 배포 스크립트 실행
- 애플리케이션 실행 확인

#### 7. CORS 테스트 코드 작성
- `CorsAcceptanceTest.java` 파일 생성
- OPTIONS 요청 테스트 작성
- CORS 헤더 검증 로직 작성

#### 8. API 테스트
- 배포된 서버의 API 엔드포인트 테스트
- Postman 또는 curl을 사용한 테스트
- 클라이언트 연동 테스트

### 배포 환경 정보
- **서버**: AWS EC2 (t3.medium)
- **운영체제**: Amazon Linux 2023
- **포트**: 8080
- **Java 버전**: 17 이상

### 클라이언트 연동 정보
- **API 엔드포인트**: `/api/products`, `/api/orders`, `/api/wishlist`, `/oauth/kakao/login`
